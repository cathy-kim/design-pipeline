# Craft — 흔한 AI 미감을 피하는 법

> Anthropic `frontend-design` 스킬(Apache-2.0, 스킬 루트 `LICENSE.txt`)에서 가져와 design-pipeline 계약에 맞게 고쳤다.
> 원본은 "폰트·색을 대담하게 고르라" 고 하지만, 여기서 **색·폰트·radius·그림자는 이미 `.design/system/` 이 정했다.**
> 대담함은 토큰을 바꾸는 데서가 아니라 **토큰을 배치하는 방식**에서 나온다.

## 1. 코딩 전에 방향을 정한다

`.design/brief.md` 를 읽고 네 줄로 적는다(작업 노트, 산출물 아님):

- **목적**: 이 화면이 푸는 문제와 쓰는 사람.
- **톤**: brief 의 결정된 톤 + `brand_config.brand.mood`. 극단 하나를 고른다 — 극단적 미니멀, 에디토리얼/매거진, 브루탈리스트, 유틸리티/산업, 레트로-퓨처, 럭셔리/절제, 장난감 같은 등. 토큰이 허락하는 범위에서 가장 멀리 간다.
- **제약**: 프레임워크, 성능, 접근성, 대상 뷰포트.
- **차별점**: 사람이 이 화면에서 기억할 **한 가지**.

방향은 강도가 아니라 **의도**다. 맥시멀도 미니멀도 되지만, 어중간한 "무난함" 은 실패다.

## 2. 토큰 안에서 대담해지는 다섯 축

| 축 | 할 것 | 하지 말 것 |
|---|---|---|
| **타이포그래피** | `system/` 의 display/body 패밀리와 타입 스케일만 쓴다. 대비는 **크기·무게 차이를 크게** 벌려서 만든다(예: 스케일 최상단 display + 최하단 caption 의 병치). 자간·행간은 토큰의 lineHeights 안에서 조정. | 시스템에 없는 폰트 추가. Inter/Roboto/Arial 로 대체. |
| **색** | Primary 하나를 **지배적으로**, Accent 는 **날카롭게 한두 군데**, 나머지는 Neutral 스케일. 한 화면 3색. | 새 hex 값. 같은 계위 요소에 다른 색. 보라 그라디언트 on 흰 배경. |
| **공간 구성** | 비대칭, 겹침, 대각 흐름, 그리드를 깨는 요소 하나, 넉넉한 여백 **또는** 통제된 밀도. 그리드 유형(regular / bento / golden ratio / asymmetric / modular)을 목적에 맞게 고른다. | 모든 섹션 가운데 정렬. 균등 3열 카드 반복. |
| **모션** | 한 번의 잘 짜인 페이지 로드(staggered reveal, `animation-delay`)가 흩어진 마이크로 인터랙션보다 낫다. HTML 은 CSS 우선, React 는 Motion(framer-motion). 시간·easing 은 `brand_config.motion`. `prefers-reduced-motion` 존중. | 모든 요소에 hover 바운스. |
| **배경·디테일** | 단색 대신 분위기: 노이즈/그레인, 기하 패턴, 레이어드 투명도(토큰 색의 알파), 토큰의 그림자, 장식적 구분선. | **네온 글로우, 글래스모피즘(backdrop-blur 반투명 패널), 그라디언트 보더, pill 버튼** — 계약 §1-6 금지, design-qa 가 잡는다. |

## 3. 계위 순서

크기/무게 → 간격 → 명도 → (최후 수단) 색. 무언가를 강조하고 싶으면 먼저 키우고, 그다음 띄우고, 그다음 흐리게 하고, 그래도 안 되면 색을 쓴다.

## 4. 구현 복잡도를 비전에 맞춘다

- 맥시멀 방향 → 레이어·애니메이션·효과가 많은 정교한 코드.
- 미니멀/절제 방향 → 절제와 정밀함. 간격·타이포·미세한 디테일에 시간을 쓴다.
- 우아함은 비전을 **잘 실행**하는 데서 나온다.

## 5. 수렴 금지

같은 브랜드로 여러 화면을 만들 때도 레이아웃 아이디어는 반복하지 않는다. 화면마다 "이 맥락에서만 나올 선택" 을 하나씩 넣는다. 토큰은 같아도 구성은 달라야 한다.

## 6. 자기 점검 (생성 직후, design-qa 전에)

- [ ] 이 화면을 한 문장으로 묘사하면 "흔한 SaaS 템플릿" 이 아니라 고유한 무언가가 나오는가
- [ ] 색은 Primary + Accent + Neutral 셋뿐인가
- [ ] 모든 radius·색·그림자가 `system/` 의 이름(클래스/변수)으로 쓰였는가
- [ ] 금지 효과 네 가지가 없는가
- [ ] 차별점 한 가지가 첫 화면(above the fold)에 보이는가
